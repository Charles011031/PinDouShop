# 拼豆店 · 工位看板

10 个工位的计时/收费看板，给悉尼拼豆店用。

**线上**：https://charles011031.github.io/PinDouShop/  
**当前版本**：v0.7.4（2026-11-27）  
**门店**：Zetland（悉尼）

> 独立仓库 `Charles011031/PinDouShop`，main 分支根目录。

## 现在能做什么

- 10 个工位：选板型（智能板 / 普通板）开台，暂停 / 继续 / 结束；单价统一在顶部价格摘要里看。
- 两种计费：按小时（15 分钟进位、最低 30 分钟）或 2 小时套餐（超时按 15 分钟补）。
- 结束计时后工位进入「待结算」，可以再撤销结束回到计时。
- 结算（照搬天胡那套）：收款明细**按笔记账**，每笔可选现金 / 刷卡 / 人民币，可拆成多人混合支付；
  刷卡可填「实收（含手续费）」自动反推本金；人民币按汇率折算并记微信 / 支付宝渠道；
  少收的钱可以选「记在工位上」或「直接免除」，记在工位上的下次结算自动带上，也能从工位卡「补收上次未付」。
- 结算记录：今日收款点开可以原地修改（改时间 / 单价 / 工位 / 收款明细）或删除，不会新增一条。
- 系统**不设置烫位队列**：熨烫由店员线下处理，不在看板里跟踪。
- 今日营收/单数/使用中/平均客单统计；今日收款列出当天全部（面板内滚动）。
- 顶部四个页签：**工位 / 配件 / 员工 / 统计**（一体式分段控件，切换时选中块滑过去）。
- 工位页下方有「结算记录」全表：按日期分组、每组小计、可搜索、分页，点一行直接进编辑。
- 统计页：按日 / 按周 / 按月（可前后翻），看营业总额、台费、其它费用、刷卡手续费、人民币、平均客单、计时总长，
  以及「预估营业额（含进行中 + 待结算）」；明细按日期分组，可一键生成统计文案。
- 员工页：员工名单、上下班打卡（员工卡上可填上班时间，留空=现在；自动给其他人下班）、手动补录与修改、班次指定；
  工资汇总按白班/晚班时薪 + 忙日加成，支持按月 / 按周查看。
- 设置分散在对应页面：工位页「⚙ 价格」改板型时价 / 套餐价 / 套餐分钟 / 超时价；
  统计页「⚙ 收款设置」改刷卡手续费 / 会员优惠 / 人民币汇率与加点；员工页「💰 工资汇总」改时薪与忙日规则。
  价格只影响新开的工单，进行中的按开台时锁定的价格结算。
- 配件页（v0.7.0 新增）：商品和分类都由店主自己加，没有预设商品——
  点「＋ 新增商品」填名称 / 分类 / 单价 / 库存；分类在「＋ 分类」里自己起名（工具 / 材料 / 成品，或按你习惯）。
  商品可以放照片（v0.7.1）：选图后拖动位置、滑杆或滚轮缩放，存成 200×200 小图，卡片上直接显示；
  照片跟着商品一起同步，数据没变时用 ETag 跳过下载，不会因为照片变慢。
  商品卡点一下加购，右下角购物车可以「挂到工位」（随台费一起结）或「单独结算」（只买配件、不开台）；
  库存为 0 自动售罄、不能点，盘点记录能看到每一笔库存变动。
- 结算时配件自动带出：工位上挂着的配件在结算弹窗里单独一块「🧩 配件」，和其它费用一起算进账单；
  结算弹窗里也能「＋ 加配件」临时加，不用回配件页。
  配件库存只在落单时扣（结算 / 零售 / 改单差额 / 删单归还），挂账期间不扣。
- 零售单（只买配件）：不占工位，生成一条「配件零售」记录，现金 / 刷卡 / 人民币都能收，
  会出现在配件页「配件销售记录」、今日收款、结算记录全表和统计里。
- 统计页「其它费用」卡副标题会写「其中配件 $X」，配件不单独占一张卡；工资忙日营业额含配件。
- 多设备同步：Firebase Realtime Database 新表（与天胡门店数据隔离），3 秒轮询；断网自动用本机缓存，联网后补写。

## 数据

- 浏览器本地：`localStorage` 键 `pindou_board_v1`。
- 云端：**独立 Firebase 项目** `pindoushop` 的 Realtime Database，路径 `shops/<独立 key>/state`；和天胡项目完全分开。
- 配件数据就在同一个 `state` 里：`items`（商品）、`cats`（自定义分类）、`stockLogs`（库存变动），
  工位上的挂账存在 `seats[i].cart`；结算记录里多 `kind`（station / retail）、`items`、`accessories` 三个字段，老记录自动补默认值。
- 当前是 Firebase **测试模式**（30 天后自动锁），规则是匿名读写；**网址不要发群/朋友圈**。
- 正式营业前二选一：① 收紧规则到具体路径 + 门店 PIN；② 开 Anonymous Auth，规则改成 `auth != null`（页面需加登录，我可以加）。

## 价格

页面里的默认价只是占位示意：智能板 A$15/h、普通板 A$10/h；2 小时套餐 A$28 / A$18。
老板定价后，在页面右上角「⚙ 设置」里改即可，不用改代码。

- 部署：GitHub Pages（main 分支根目录）。


## 发布工具（模仿天胡）

`发布.py` 做 8 件事：

1. 版本体检：`index.html` / meta / README 版本表 / `版本记录.md` / README 当前版本必须一致
2. 更新日志检查 + 文件检查 + Chrome 无头冒烟（10 个工位、版本号、DOM 正常）
3. Firebase 读写检查（state、`__sysVer`、临时探针写入/删除）
4. GitHub 权限 + Pages 状态检查
5. 发布锁：同一时间只能一个发布；异常退出自动释放
6. GitHub 一次 commit 原子提交 5 个文件
7. 等线上真的返回新版本（最多 3 分钟）
8. 写 Firebase `__sysVer` 广播；打开中的页面 20 秒内自动刷新（有弹窗/计时中先弹提示条）

```bash
python3 发布.py            # 正式发布
python3 发布.py --check    # 只体检
python3 发布.py --no-tests # 跳过 Chrome 冒烟
python3 发布.py --no-broadcast  # 推送并等线上，但不广播
```

Mac 也可以双击 `发布.command`。

状态文件：`.发布状态.json`；日志：`发布日志/当前.log`；锁：`.发布锁`（都在 `.gitignore` 里）。
